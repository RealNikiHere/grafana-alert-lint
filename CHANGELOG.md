## [0.1.0] — 2026-11-24

Первая версия. Ничего не публиковалось, поэтому раздел «Unreleased» не нужен.

### Добавлено

- 12 проверок (GAL001–GAL012) для провижиненных правил алертов Grafana:
  фильтрующее сравнение при `noDataState: Alerting`, `NoData`, отсутствие
  или неизвестное `noDataState`, `for`, `<` в аннотациях (Telegram `400`),
  `condition`, дубли `uid`/`title`, `severity`, `summary`, `execErrState`,
  `for` короче интервала группы, отсутствие идентичности правила.
- CLI `galint` с `--format text|json`, `--strict`, разворотом каталогов.
- Общее состояние уникальности `uid`/`title` на весь запуск: дубли ловятся
  между документами и файлами, а не только внутри одного.
- 77 тестов, `ruff`, CI на Python 3.10–3.13, workflow публикации в PyPI
  через OIDC Trusted Publishing.
- Лицензия Apache-2.0.

### Исправлено до релиза (по итогам аудита)

- `KeepLast` принимается как валидное значение `noDataState` и `execErrState`;
  `noDataState: Error` — отвергается.
- GAL001 больше не срабатывает на `==`/`!=` внутри матчеров лейблов
  и игнорирует сравнения с `bool`; зато ловит `>`, `<`, `>=`, `<=`.
- GAL005 проверяет только `<`: `>` в тексте Telegram не ломает.
- Duplicate `uid` ловится для числовых значений и между файлами.
- GAL006 срабатывает, когда `condition` есть, а `data` пуст.
- `parse_duration` понимает `w`, `y` и дробные значения (`1.5s`);
  при отсутствии `interval` группы используется дефолт Grafana (1 минута).
- CLI не теряет находки, если один из путей не прочитался; в JSON-отчёте
  появилось поле `path_errors`.
- CI-шаг «регрессия должна падать» больше не ломается из-за `pipefail`.
